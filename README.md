## 🛠️ Conteúdo do Treinamento

### 💻 Prática com Código (.js)

Os arquivos práticos contêm desafios com testes automatizados que rodam direto no seu terminal. Você aprenderá a dominar métodos como:

- **Filtros e Mapeamentos:** `map()`, `filter()` para higienização e transformação de payloads.
- **Agregações Complexas:** Uso avançado de `reduce()` para cálculos financeiros e agrupamento por categorias.
- **Manipulação de Strings:** `split()`, `slice()` e Regex para paginação de dados e geradores de slugs amigáveis.
- **Buscas Dinâmicas:** Diferenças práticas na aplicação de `indexOf()`, `includes()`, `some()` e `every()`.

### 🧠 Simulados Teóricos (.md)

Arquivos focados na parte verbal e arquitetural das entrevistas para vagas Full Stack:

1. **Event Loop & Assincronismo:** Como o Node.js escala sem travar a thread principal.
2. **Fundamentos do JS:** Entendendo coerção de tipos (`==` vs `===`) e o comportamento do _Hoisting_.
3. **Escopo Avançado:** Como e quando aplicar _Closures_ para encapsulamento.
4. **Design de APIs:** Quando escolher a arquitetura REST tradicional ou a flexibilidade do GraphQL.
5. **Estratégias de Cache:** Introdução ao Redis para otimização de leitura de banco de dados.
6. **Bancos de Dados:** Critérios de decisão entre modelagens Relacionais (SQL) e Não-Relacionais (NoSQL/MongoDB).
7. **Segurança Avançada:** Fluxo de autenticação JWT e os riscos de armazenamento (_XSS_ vs _HttpOnly Cookies_).
8. **Políticas de Navegador:** Como funciona e como configurar corretamente as permissões de CORS.
9. **Soft Skills & Prazos:** Como gerenciar gargalos técnicos e se comunicar de forma proativa com a equipe.
10. **Gerenciamento de Crises:** Plano de ação imediato para lidar com deploys que apresentam falhas em produção.

## 🚀 Como Executar os Desafios Práticos

Para rodar os testes automáticos e verificar se a sua lógica está correta, certifique-se de ter o [Node.js](https://nodejs.org) instalado em sua máquina e siga os passos abaixo:

1. **Clone o repositório:**

   ```bash
   git clone https://github.com
   ```

2. **Navegue até a pasta do projeto:**

   ```bash
   cd NOME_DO_REPOSITORIO
   ```

3. **Execute o arquivo de desafio que deseja resolver (exemplo com o Bloco 3):**

   ```bash
   node desafios_3.js
   ```

4. **Observe o console:** O sistema indicará automaticamente quais desafios passaram (`✅`) e quais falharam (`❌`) com mensagens detalhadas sobre o resultado esperado.

## 💡 Dica de Ouro do Professor Leo Gomes

- **Se você está no Básico:** Foque em entender como os dados entram e saem de métodos simples como `filter` e `includes`. Não tenha medo de usar `console.log()` para rastrear suas variáveis passo a passo.
- **Se você está no Avançado:** Desafie-se a refatorar os códigos para usarem menos linhas (funções de uma linha com arrow functions) ou otimizar a complexidade de tempo de execução de $O(n)$ para $O(1)$ usando indexação por objetos.
- **Para Todos:** Abram os arquivos `.md` e pratiquem responder às perguntas em voz alta. A capacidade de explicar o seu código de forma técnica e clara vale tanto quanto saber digitá-lo!
